# Manual Press v0.6.0 출시 안내

Manual Press의 최신 버전 v0.6.0이 공개되었습니다! 이번 업데이트는 문서 작성, 배포, 그리고 사용자 경험 향상에 초점을 맞춘 다양한 기능과 개선 사항을 포함하고 있습니다.

## 주요 변경 사항

- **REPL Works 문서 지원**: document2 SaaS 허브를 위한 REPL Works 문서 작업 문서를 추가하였으며, 자세한 내용은 [여기](https://github.com/replworks/manualpress/pull/26)를 참고하세요.
- **자동 실행 워크플로우 및 Ask-Human 스크립트**: 자동화된 배포와 사용자 지원을 위한 워크플로우와 스크립트를 도입하였으며, 관련 내용은 [여기](https://github.com/replworks/manualpress/pull/27)를 확인하세요.
- **Laravel 13 기반 CLI 교체**: 기존 레거시 CLI를 Laravel 13 프로젝트 기반으로 교체하여 성능과 유지보수성을 향상시켰습니다. 자세한 내용은 [여기](https://github.com/replworks/manualpress/pull/29)를 참고하세요.
- **GitHub 연동 기능 강화**: GitHub Sign-in, Author Sign-in, 프로젝트 목록, 빌드 이력, 프로젝트 편집 등 다양한 GitHub 연동 기능이 새롭게 추가 및 개선되었습니다. 자세한 내용은 각 PR 링크를 참고하시기 바랍니다.
- **사이트 UI 및 스타일 개선**: 홈 페이지, 프로젝트 리스트, 빌드 히스토리, 설정 페이지 등 사용자 인터페이스(UI)가 더욱 세련되고 직관적으로 개선되었습니다.
- **문서 렌더링 및 기능 향상**: MathJax, Mermaid 다이어그램, 코드 블록, 검색 기능 등 문서의 가독성과 기능성이 크게 향상되었습니다.
- **커스텀 도메인 및 배포 지원 강화**: 커스텀 도메인 검증, DNS 체크, GitHub Pages 배포 등 배포 관련 기능이 강화되어 안정적인 배포 환경을 제공합니다.
- **로컬 개발 도구 지원**: `docs:check`, `docs:preview` 명령어를 통해 로컬 환경에서도 문서 검증과 미리보기를 지원합니다.

## 새롭게 추가된 기능과 개선 사항

- 문서 내 섹션 및 페이지 네비게이션 개선
- 사이트 검색, SEO 최적화, 사이트 appearance 설정 등 사용자 편의성 향상
- 프로젝트 삭제, 버전 선택, 빌드 시작 등 핵심 작업의 안정성 강화
- 다양한 UI 스타일링과 반응형 디자인 적용
